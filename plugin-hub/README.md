# Plugin Hub manifest

`gamemargins` is the file a pull request to https://github.com/runelite/plugin-hub adds as `plugins/gamemargins`
once this repository is public. Before submitting, set `commit=` to the full hash of the commit to publish
(`git rev-parse HEAD`), and keep the `warning=` line: the Plugin Hub asks every plugin that sends anything to a
third-party server to carry it. The pull request's description ends with `Generated-by: Claude Code`.
